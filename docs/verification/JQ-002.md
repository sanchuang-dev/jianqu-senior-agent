## 已执行且通过

1. 原生 Gradle Wrapper `./gradlew :app:assembleDebug :app:lintDebug`：构建成功；Lint 0 errors / 3 warnings（SDK target / version 提醒、Android backup 配置提示）。
2. 在 Android 13 AVD 执行 `adb install -r`：显示 `Success`。
3. 初始版本：`adb shell cmd package set-home-activity cn.sanchuang.jianqu/.LauncherActivity` 返回 `Success`；按 Home 后 `topResumedActivity` 为 `cn.sanchuang.jianqu/.LauncherActivity`。
4. 初始版本：使用 `uiautomator dump` 得到真实系统应用项，如 Calendar、Chrome、Clock、Files；点击 **Clock** 后，`topResumedActivity` 为 `com.google.android.deskclock/com.android.deskclock.DeskClock`；再按 Home 返回 `cn.sanchuang.jianqu/.LauncherActivity`。
5. 初始版本：在测试 AVD 中临时禁用 `com.google.android.deskclock` 后，Launcher 列表不再出现 Clock；重新启用后出现 Clock。**这验证的是应用可用状态变化，不等于真正执行了安装/卸载测试**。Clock 已恢复为 enabled。
6. 修订版：将来自用户上传 `sanchuang-web.zip` 的 `logo-icon-512.png` 转成轻量 `sanchuang_logo.png`，用于桌面与 APK 图标；修复「读取应用失败误报为无应用」的问题；再次运行构建和 Lint 成功，重新安装 APK 返回 `Success`，按 Home 后 Activity 仍为本 Launcher。
7. 修订版 APK SHA-256：`cad631c0ea2247705674e82880324c7022959b9734e916f543ee9101f229a5a0`，大小约 2.3 MB。截图：![Android 13 竖屏界面](jq-002-home-android13.png)。
