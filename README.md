# 见趣 · 银龄私人 Agent（Android 原型）

> 三创科技 / Jianqu Senior Agent Prototype  
> 当前阶段：**需求定义，尚未开发或交付 APK**。首个目标终端为普通安装 Android 11+、4GB RAM 的闺蜜机。

## 这个项目做什么

一套可下载安装的第三方 Android Launcher：展示品牌和设备上所有可启动的已安装应用；演示设备级订阅、自主开通与「我的闺蜜机」套餐服务；体验面向老年人的私人 AI Agent（多种角色与简单办事）。

**本期只做原型**：不接真实支付，不建设养老院内部管理系统，不依赖 Root/出厂权限，不宣称系统级防绕过锁机。
